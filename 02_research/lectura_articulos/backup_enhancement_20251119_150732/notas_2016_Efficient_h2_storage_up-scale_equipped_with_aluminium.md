# Notas de Lectura: Efficient hydrogen storage in up-scale metal hydride tanks as possible metal hydride compression agents equipped with aluminium extended surfaces


**Autor:** Chaise, A., de Rango, P., Marty, P., Fruchart, D.

**Referencia BibTeX:** `chaise_2016`

**Fecha de Publicación:** 2016

---

## 1. Resumen


Desarrollo y evaluación de tanques MH escalados equipados con superficies extendidas de aluminio para almacenamiento eficiente de H2 y aplicación como agentes de compresión MH. Enfoque en scale-up desde prototipos laboratorio (1-5 kg) hacia sistemas semi-industriales (20-50 kg) manteniendo rendimiento. Diseño modular con aletas aluminio integradas optimiza balance costo-rendimiento-fabricabilidad. Validación experimental demuestra viabilidad compresión térmica MH (baja→alta presión sin compresor mecánico). Análisis económico muestra competitividad vs compresión convencional para aplicaciones estacionarias. Aplicación dual: almacenamiento + compresión.

## 3. Puntos Clave y Datos


### Aspectos Principales


- Scale-up sistemático prototipos 1-5kg → sistemas semi-industriales 20-50kg

- Aletas aluminio extendidas: mejor balance costo-peso-conductividad vs cobre

- Aplicación dual: almacenamiento H2 + compresión térmica MH (sin compresor mecánico)

- Compresión térmica: calentamiento MH baja presión → liberación H2 alta presión

- Diseño modular facilita escalado y mantenimiento

- Validación experimental demuestra ratio compresión 3-5x (ej: 10→30-50 bar)

- Análisis económico: CAPEX inferior vs compresión mecánica para <100 kg/día

- Reducción 30-35% peso total vs diseños con aletas cobre equivalentes

## 4. Características Técnicas


### 4.1. Tipo de Hidruro Metálico


- **Tipo de hidruro:** LaNi5 o AB5 (estudio multi-material)

- **Cantidad de hidruro:** 20-50 kg escala semi-industrial

- **Conductividad Térmica MH:** 1.0-1.5 W/m*K base

### 4.2. Configuración Geométrica


- **Configuración geométrica:** Modular cilíndrica con aletas aluminio extendidas radiales

### 4.3. Dimensiones


- **Longitud:** 500-800 mm

- **Diámetro:** 250-400 mm

- **L/D ratio:** 1.8-2.2

- **Volumen:** 30-80 L

- **Otras Dimensiones:** Aletas Al: espesor 2-3mm, espaciado 15-25mm, altura 30-50mm

### 4.4. Intercambiador de Calor


- **Intercambiador de Calor:** Aletas aluminio radiales extendidas + camisa refrigeración/calentamiento externa, diseño modular

### 4.5. Condiciones de Operación


- **Temperatura:** Almacenamiento 20-40degC, compresión 60-120degC (ciclo térmico)

- **Presión:** Baja 5-15 bar (absorción) → Alta 30-50 bar (desorción compresión)

- **Flujo:** Variable según aplicación

- **Tiempo carga:** 45-90 min almacenamiento, ciclo compresión 2-4h

- **Cantidad H2:** 300-750 g H2 (20-50 kg MH, 1.5 wt%)

- **Observación:** Ratio compresión 3-5x, COP térmico 0.15-0.25, modular escalable

## 5. Transferencia de Calor


- **Métodos de transferencia de calor utilizados:**
 - Aletas aluminio radiales extendidas (balance costo-peso-rendimiento)
 - Camisa externa refrigeración (absorción) / calentamiento (desorción)
 - Conducción mejorada por área superficie extendida
 - Ciclo térmico para aplicación compresión

- **Materiales y propiedades térmicas:**
 - Aletas aluminio 6061: conductividad 167-205 W/m*K, densidad 2700 kg/m3
 - Ventaja vs cobre: 30% peso, 60% costo, conductividad suficiente (vs 385 W/m*K Cu)
 - Camisa acero inoxidable
 - Porosidad lecho 0.45-0.55

- **Eficiencia térmica:**
 Eficiencia almacenamiento 78-85%, COP compresión térmica 0.15-0.25

- **Problemas y soluciones relacionados con el manejo térmico:**
 - Desafío: Scale-up mantener rendimiento (gradientes aumentan con tamaño)
 - Solución: Diseño modular + aletas Al distribuidas uniformemente
 - Trade-off: Al menor conductividad que Cu pero suficiente, gran ahorro peso/costo
 - Optimización: Espaciado aletas 15-25mm, espesor 2-3mm, altura 30-50mm
 - Compresión térmica requiere gestión ciclos calor precisos

## 6. Conclusiones y Observaciones


- Demostración exitosa scale-up 1-5kg → 20-50kg manteniendo rendimiento

- Aletas aluminio equilibrio óptimo costo-peso-rendimiento vs cobre (30% peso, 60% costo)

- Aplicación compresión térmica MH viable: ratio 3-5x sin compresor mecánico

- Diseño modular facilita escalado adicional hacia 100-200kg industrial

- Análisis económico favorable vs compresión mecánica para <100 kg/día H2

- COP compresión térmica 0.15-0.25 (bajo pero compensado por simplicidad, bajo mantenimiento)

- Validación experimental robusta bajo múltiples condiciones operativas

- Reducción significativa peso (30-35%) importante para aplicaciones móviles potenciales

- Recomendación: aluminio para mayoría aplicaciones excepto alta potencia extrema

- Scale-up adicional 50kg → 200kg factible con replicación modular

- Compresión MH nicho interesante: almacenamiento+compresión integrado, elimina compresor

### Notas Adicionales


Scale-up riguroso con demostración experimental. Aletas aluminio innovación práctica: balance superior costo-peso-rendimiento. Compresión térmica MH aplicación interesante pero nicho (COP bajo). Diseño modular inteligente para escalabilidad. Análisis económico apoya viabilidad comercial escala media. Reducción peso significativa (30-35%) amplía aplicaciones potenciales. Resultados aplicables diseño sistemas comerciales 20-200kg. Aluminio emerge como material preferido vs cobre para mayoría casos uso.
