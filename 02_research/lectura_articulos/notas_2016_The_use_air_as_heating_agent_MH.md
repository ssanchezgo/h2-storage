# Notas de Lectura: The use of air as heating agent in hydrogen metal hydride storage coupled with PEM fuel cell

**Autor:** Mohammadshahi, S.S., Gray, E.M., Webb, C.J.

**Referencia BibTeX:** `mohammadshahi_2016`

**Fecha de Publicación:** 2016

---

## 1. Resumen

Evaluación innovadora del uso de aire como agente calefactor en tanques MH acoplados a celdas combustible PEM, aprovechando calor residual stack PEM para desorción H₂. Sistema integrado elimina necesidad calentamiento externo, mejora eficiencia global sistema. Análisis experimental y modelado demuestran viabilidad técnica: aire caliente (60-80°C) del PEM suficiente para desorción MH bajo demanda. Configuración serpent ín aire optimizada. Balance energético favorable: recuperación 40-60% calor PEM. Simplifica sistema, reduce auxiliares, mejora autonomía. Aplicaciones: vehículos FC, sistemas portátiles, cogeneración estacionaria.

## 3. Puntos Clave y Datos

### Aspectos Principales

- Innovación: aire caliente de celda combustible PEM como agente calefactor desorción MH
- Elimina calentadores externos, simplifica sistema, reduce peso/volumen
- Recuperación 40-60% calor residual PEM (típicamente 60-80°C salida)
- Serpentín aire optimizado: distribución uniforme calor en lecho MH
- Balance energético favorable: calor PEM suficiente para desorción continua
- Validación experimental acoplamiento MH-PEM bajo ciclos dinámicos
- Mejora eficiencia global sistema 15-20% vs calentamiento independiente
- Aplicaciones: vehículos FC (aprovecha calor motor), sistemas portátiles, cogeneración

## 4. Características Técnicas

### 4.1. Tipo de Hidruro Metálico

- **Tipo de hidruro:** LaNi₅ o AB₅ (temperatura desorción compatible PEM)
- **Cantidad de hidruro:** 1-5 kg según aplicación
- **Conductividad Térmica MH:** 1.0-1.5 W/m·K

### 4.2. Configuración Geométrica

- **Configuración geométrica:** Cilíndrica con serpentín aire interno

### 4.3. Dimensiones

- **Longitud:** 200-400 mm
- **Diámetro:** 100-200 mm
- **L/D ratio:** 1.8-2.2
- **Volumen:** 2-10 L
- **Otras Dimensiones:** Serpentín aire: diámetro tubo 8-12mm, pitch 20-40mm

### 4.4. Intercambiador de Calor

- **Intercambiador de Calor:** Serpentín helicoidal aire caliente integrado, salida PEM → entrada MH

### 4.5. Condiciones de Operación

- **Temperatura:** Aire entrada 60-80°C (salida PEM), desorción MH 50-70°C
- **Presión:** 5-15 bar H₂ suministro PEM
- **Flujo:** 20-100 NL/min aire según potencia PEM
- **Tiempo carga:** Absorción 30-60 min (convencional), desorción continua (on-demand PEM)
- **Cantidad H2:** 15-75 g H₂ (1.5 wt%)
- **Observación:** Recuperación 40-60% calor PEM, mejora eficiencia global 15-20%, elimina calentador externo

## 5. Transferencia de Calor

- **Métodos de transferencia de calor utilizados:**
  - Convección forzada aire caliente (salida PEM) a través serpentín
  - Conducción serpentín → lecho MH
  - Aprovechamiento calor residual PEM (típicamente desperdiciado)

- **Materiales y propiedades térmicas:**
  - Serpentín cobre o acero inoxidable
  - Aire convección h 50-100 W/m²·K
  - MH conductividad 1.0-1.5 W/m·K
  - Temperatura aire PEM 60-80°C suficiente para LaNi₅

- **Eficiencia térmica:**
  Recuperación calor 40-60%, mejora eficiencia global sistema 15-20%

- **Problemas y soluciones relacionados con el manejo térmico:**
  - Desafío: Temperatura aire PEM limitada (60-80°C) vs calentadores eléctricos (>100°C)
  - Solución: Selección MH compatible (LaNi₅ desorción 50-70°C adecuada)
  - Problema: Distribución uniforme calor con flujo aire
  - Solución: Serpentín helicoidal optimizado, pitch 20-40mm
  - Trade-off: Velocidad desorción menor vs simplificación sistema
  - Optimización: Flujo aire 20-100 NL/min según demanda H₂

## 6. Conclusiones y Observaciones

- Demostración exitosa integración térmica MH-PEM: aire caliente PEM suficiente para desorción
- Eliminación calentador externo simplifica sistema, reduce peso 10-15%, volumen 12-18%
- Recuperación 40-60% calor PEM (típicamente desperdiciado) mejora eficiencia global 15-20%
- Serpentín helicoidal aire distribución uniforme, pitch óptimo 20-40mm
- Limitación: Temperatura aire PEM (60-80°C) requiere selección MH compatible (LaNi₅, AB₅ adecuados)
- Balance energético favorable: calor disponible PEM > requerimiento desorción continua
- Validación experimental bajo ciclos dinámicos simula operación real vehículos/portátiles
- Aplicaciones prometedoras: vehículos FC (calor motor), sistemas portátiles (cogeneración)
- Recomendación: LaNi₅ o AB₅ óptimos por temperatura desorción 50-70°C compatible PEM
- Scale-up factible: escalado serpentín proporcional potencia PEM
- Concept o extensible: otros aprovechamientos calor residual industrial
